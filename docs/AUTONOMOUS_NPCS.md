# Source autonomous NPC movement

The compiler extracts movement delays, cardinal direction tables, initial facing, range-enabled types, normal-step length, directional impassability predicates and the original LCG constants from the pinned pret C source. Those inputs are hashed alongside the source event program. They are generated data, not numbers chosen by the renderer.

The runtime carries fractional frames into a 60-frame source clock and visits objects in ascending source slot order. Wander-around, horizontal/vertical wandering and look-around use the source medium-delay table and original direction selection. Random seed zero is explicit for reproducible testing; it is not synchronized to a cartridge's global RNG or other game systems. Normal autonomous movement reserves destination and previous tiles for its 16 source frames while interpolating the display position. Source range zero is promoted to one for range-enabled movement types, as at original spawn. Map collision, directional blocking, elevation and visible object/player reservations reject invalid destinations.

New autonomous decisions pause during a source script or dialogue. An already reserved step finishes before lock/lockall continues, avoiding a frozen half-cell pose. This is a conservative global script lock; original per-object lock scope and every action-state boundary still require parity review. Scripted movement remains a separate path. Player key movement reserves both ends of its step, and scripted NPC endpoints also block the player. These changes do not make general unsupported scripted-movement rollback complete.

Normal source wandering explicitly selects the licensed Walk clip even when the 200 cm source grid produces high world velocity. The explicit source gait keeps Walk selected between source clock updates, avoiding zero-velocity render frames restarting Idle. Walk pose probes exclude six settling frames and require four further pose samples (ten total), fitting a sixteen-frame step; idle/run probes retain eighteen samples. Actual figure pacing/foot contacts remain subject to inspection and owner acceptance. No whole motion was authored.

Current coverage excludes autonomous back-and-forth and walk-in-place types used by hidden intro movers, trainer-follow variants, later decorated-room state coverage, dynamic layout/behavior replacement and ground effects. Fixed baseline captures pause story progression; `tools/render_wander_scenario.sh` is the separate actual story-ticking render route. Each map uses an isolated post-clock source fixture; forced capture map jumps must not carry an unfinished dialogue into unrelated scenes. Success requires reset receipts for all six maps, completed native town wander steps, settled Walk pose/time evidence and all six saved views; opening those views is a separate visual check.

Validation is recorded after native execution; source changes alone are not a pass. Full GOAL.md remains active.
